# CrunchGo 第三方对接需求文档

本文档详细列出了 CrunchGo 街边点餐系统在实施过程中需要申请、配置和集成的第三方服务与资源。请提前准备好相关账号和资质，以免影响开发进度。

## 1. 微信生态 (WeChat)

### 1.1 微信小程序 (Mini Program)
- **用途**: 顾客端扫码点餐入口。
- **需要**:
  - **AppID (小程序ID)**: 开发和上线必须。
  - **AppSecret (小程序密钥)**: 后端服务器换取用户 OpenID 使用。
  - **类目选择**: 建议选择“餐饮-点餐平台”或“餐饮-门店/自提”，需提交《食品经营许可证》。
  - **服务器域名配置**:
    - `request` 合法域名: `https://api.your-domain.com`
    - `uploadFile` 合法域名: `https://api.your-domain.com` (如需上传图片)
    - `downloadFile` 合法域名: `https://img.your-domain.com` (图片CDN)

### 1.2 微信支付 (WeChat Pay)
- **用途**: 顾客在线支付订单。
- **需要**:
  - **MchID (商户号)**: 微信支付商户平台的账号。
  - **API v3 密钥**: 设置在商户平台，用于接口签名加密。
  - **API 证书**: `apiclient_key.pem` 和 `apiclient_cert.pem`，需下载并安全保存在服务器端。
  - **JSAPI 支付权限**: 在商户平台关联上述小程序 AppID。

## 2. 硬件设备 (Hardware)

### 2.1 小票打印机 (Printer)
- **方案 A: 云打印机 (推荐)**
  - **品牌示例**: 飞鹅 (Feie)、易联云 (Yilianyun)、芯烨 (Xprinter)。
  - **优势**: 无需连接手机/电脑，直接连 WiFi/4G，服务器远程下发指令，接单更稳定，适合无人值守或忙碌场景。
  - **需要**:
    - **开发者账号**: 注册打印机厂商的开发者平台。
    - **API Key / Secret**: 用于后端调用打印接口。
    - **终端编号 (SN)**: 打印机底部的序列号，用于绑定设备。

- **方案 B: 蓝牙打印机 (MVP 备选)**
  - **品牌示例**: 佳博、汉印等支持 ESC/POS 指令的蓝牙热敏打印机。
  - **优势**: 成本极低，无需外网。
  - **劣势**: 需连接手机/平板，且小程序必须保持前台运行或使用特定后台能力，稳定性较差。
  - **需要**:
    - 无需额外 API，但前端需集成蓝牙连接库 (`wx.openBluetoothAdapter`)。

### 2.2 叫号屏/音响 (Optional)
- **方案**: 使用闲置平板或手机连接蓝牙音箱。
- **实现**: 商家端小程序/网页版接收到“请取餐”状态变更时，自动播放 TTS 语音：“请 A102 号顾客取餐”。

## 3. 基础设施 (Infrastructure)

### 3.1 云服务器 (Cloud Server)
- **推荐**: 腾讯云/阿里云 (国内访问速度快，备案方便)。
- **配置**:
  - CPU: 2核
  - 内存: 4GB (运行 NestJS + Redis + PostgreSQL 的最小推荐)
  - 带宽: 3Mbps+
- **系统**: Ubuntu 22.04 LTS 或 CentOS 7.9。

### 3.2 域名与 SSL 证书
- **域名**: 需备案 (ICP 备案 + 公安备案)，否则无法被微信小程序调用。
- **SSL**: 必须开启 HTTPS，可申请免费证书 (Let's Encrypt 或云厂商免费版)。

### 3.3 对象存储 (OSS/COS)
- **用途**: 存储菜品图片。
- **推荐**: 阿里云 OSS 或 腾讯云 COS。
- **优势**: 访问速度快，减轻服务器带宽压力。
